# R4 E1.1 — UI и следы пуль

Пересобрать **XR_3DA и xrRender_R4, Release Win32**, заменить EXE и DLL вместе.
ABI E1 сохранён; обе части должны иметь одинаковые новые хеши исходников и
шейдеров. HLSL встроен в EXE, обновление gamedata не требуется.

- UI и консоль: используемые в кадре атласы и шрифты получают место в DDS-кеше
  до материалов сцены. Сначала закрепляются все уже загруженные UI-ресурсы,
  затем повторяются отказы по бюджету. Общий бюджет не увеличен; отсутствующие
  файлы и runtime-текстуры сохраняют отдельную обработку.
- Декали: явная классификация статических и скелетных wallmarks работает и без
  снэпшота, включая старые материалы без флага bWmark. Восстановлены операции
  цвета/альфы CBlender_Screen_SET и stub_default_ma/simple из X-Ray 1.6.
  Декаль меняет только RGB albedo перед освещением, один раз за кадр.
- UI_TEXTURE, DDS_RESIDENCY и DYNAMIC_TEXTURE имеют отдельные ограниченные
  разделы диагностики; записи UI не вытесняются ранними материалами сцены.

Основание: снэпшот Бара 24.10.2026 12:06:23 — 402632460 из 402653184 байт DDS,
2784 вытеснения, CHECKER_FALLBACK для ui_common, ui_icon_equipment и шрифта.
Снэпшот Кордона 12:09:10 — динамические декали ошибочно проходят через
PSForwardLocal вместо отдельного прохода wallmarks.

Проверки: конкуренция UI/сцены за кеш, открытие консоли, повторное восстановление,
пропавший файл и потеря устройства; формула нейтрального texel и затухания;
однократный проход декалей с несколькими источниками света; существующие
наборы UI, capture, материалов, моделей, ABI и телеметрии.
MSVC, настоящий HLSL-компилятор и проверка на GPU здесь недоступны.

В игре проверить прежние точки: Бар с открытием/закрытием консоли и иконками UI;
бак на Кордоне со следами пуль при включённом/выключенном фонарике.
